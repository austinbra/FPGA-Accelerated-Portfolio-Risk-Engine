# Project documentation (public)

These files are the **maintained, public** project notes for contributors and readers (e.g. resume / GitHub).

| File | Purpose |
|------|---------|
| [`IMPLEMENTATION_STATUS.md`](IMPLEMENTATION_STATUS.md) | What is implemented, timing/utilization summary, validated prices |
| [`ROADMAP.md`](ROADMAP.md) | Milestones and next architectural steps |
| [`VALIDATION.md`](VALIDATION.md) | Commands and gate criteria |
| [`FPGA_BUILD.md`](FPGA_BUILD.md) | Vivado flows, virtual benchmark, optional on-board programming |

## Private local notes (not in Git)

If you clone this repo for personal use, you may create a **`.user/`** directory at the repo root. That path is **listed in `.gitignore`** so checklists, Obsidian handoff text, or other non-public notes stay on your machine only. Nothing in `.user/` is required to build or simulate the design.
